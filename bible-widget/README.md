# 말씀 위젯 (Bible Widget)

홈 화면에서 바로 스크롤해서 읽는 안드로이드 성경 위젯입니다. 성경 본문은 대한성서공회 개역개정판입니다.

- **제목 줄이 없습니다.** 둥근 사각형 안에 본문만 있습니다. 위치(예: `창세기 1:1`)는 첫 절 앞에 작은 회색 글씨로만 붙습니다.
- **스크롤해서 읽습니다.** 위젯 안을 위아래로 밀면 본문이 계속 이어집니다.
- **4×1 한 줄 크기도 됩니다.** 세로 1칸으로 줄이면 첫 줄이 가운데 오도록 여백이 맞춰지고, 스크롤하면 나머지가 보입니다.
- **완전한 검정/흰색.** 다크(검정 바탕·흰 글씨), 라이트(흰 바탕·검정 글씨), 또는 휴대전화의 다크 모드를 따르는 설정 중에서 고릅니다.
- **배경 투명도.** 0%(불투명)부터 100%(배경 없이 글자만)까지 10% 단위로 조절합니다. 글자는 투명해지지 않습니다.

## 세 가지 표시 방식

| 방식 | 보이는 것 | 넘기기 |
| --- | --- | --- |
| **오늘의 말씀** | 하루에 한 구절 (끝에 작은 글씨로 `빌립보서 4:19`) | 자정마다 바뀜 |
| **성경 읽기** | 한 장 전체를 절마다 한 줄씩 | 장 맨 끝의 `‹ 이전 장 · 창세기 1장 · 다음 장 ›` |

| **교독문** | 새찬송가 교독문. 인도자 줄은 보통 글씨, 회중 줄은 **굵은 글씨**로 번갈아 | 맨 끝의 `‹ 이전 · 1. 시편 1편 · 다음 ›` |

교독문은 지금 1–87번(시편·잠언·이사야·복음서·서신서 등 장 단위)을 고를 수 있습니다.
목차의 장 전체를 보여 주므로, 찬송가가 긴 장에서 일부 절만 고른 교독문(예: 시편 119편)은 찬송가보다 길게 나옵니다.
88–137번(세례, 성탄절, 부활절 같은 절기·행사 교독문)은 여러 곳을 엮은 것이라 성경 범위를 확인한 뒤 추가할 예정입니다.
목록은 `core/ResponsiveReadings.kt`에 번호·제목·성경 범위만 들어 있고, 본문은 성경과 똑같이 기기에서 받아옵니다.

성경 읽기에서 가운데 장 이름(`창세기 1장`)을 누르면 설정 화면이 열려 책과 장을 고를 수 있습니다.
위젯마다 설정이 따로라서, 예를 들어 4×1 "오늘의 말씀"과 4×4 "성경 읽기"를 함께 둘 수 있습니다.

설정 항목: 표시 방식, 읽을 위치(책·장), 배경 색상(휴대전화 설정 따름/라이트/다크), 투명도(0–100%, 11단계),
글꼴(고딕/명조), 글자 굵게, 글자 크기(12–28, 9단계), 절 번호·출처 표시.
설정 화면 위쪽의 미리보기는 실제 배경화면 위에 그려져서 투명도와 글자 크기를 바로 확인할 수 있습니다.

## 설치

### APK 받아서 설치하기

1. 이 저장소의 **Actions** 탭 → `bible-widget` 워크플로의 가장 최근 성공한 실행을 엽니다.
2. 아래쪽 **Artifacts**의 `bible-widget-apk`를 받아 압축을 풀면 `app-debug.apk`가 있습니다.
3. 휴대폰에서 APK를 열어 설치합니다. ("출처를 알 수 없는 앱" 설치 허용이 필요할 수 있습니다.)

CI가 매번 같은 서명 키를 쓰도록 캐시해 두지만, 캐시가 만료되면(7일 넘게 빌드가 없을 때 등) 키가 바뀔 수 있습니다.
그때는 기존 앱을 지우고 새로 설치해야 합니다.

### Android Studio로 빌드하기

`bible-widget` 폴더를 Android Studio에서 열고 실행하거나, 터미널에서:

```bash
cd bible-widget
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # 단위 테스트
```

JDK 17 이상, Android SDK 35가 필요합니다. 최소 지원 버전은 Android 8.0(API 26)입니다.

## 위젯 놓기

1. 홈 화면 빈 곳을 길게 누르기 → **위젯** → **말씀 위젯**을 끌어다 놓습니다. (앱을 열어 "홈 화면에 위젯 추가"를 눌러도 됩니다.)
2. 설정 화면에서 방식·테마·글자 크기를 고르고 **저장**.
3. 위젯 테두리를 끌어 크기를 바꿉니다. 기본은 4×2, 세로 1칸(4×1)까지 줄어듭니다.
4. 나중에 설정을 바꾸려면: 위젯 길게 누르기 → 설정(Android 12 이상), 또는 앱을 열어 "내 위젯 설정"에서 해당 위젯 카드를 누르기.

### 잠금화면

위젯은 잠금화면(keyguard) 위젯으로도 선언되어 있어서, 잠금화면에 다른 앱 위젯을 둘 수 있는 기기에서는 잠금화면 위젯 목록에도 나타납니다.
다만 안드로이드는 5.0부터 휴대폰 잠금화면 위젯을 없앴고, 최근 버전과 일부 제조사에서만 다시 지원하므로 기기마다 다릅니다.
기기가 다른 앱의 잠금화면 위젯을 허용하지 않으면 잠금화면에는 둘 수 없습니다.

## 본문과 저작권

- 본문은 [대한성서공회 성경읽기](https://www.bskorea.or.kr/bible/korbibReadpage.php) 페이지의 개역개정판(`version=GAE`)을 씁니다.
- 이 저장소와 APK에는 **성경 본문이 들어 있지 않습니다.** 위젯이 필요한 장을 그때그때 휴대폰에서 받아 앱 저장공간에 보관합니다. 한 번 받은 장은 인터넷 없이도 보이고, 다음 장은 미리 받아 둡니다.
- 받아 둔 본문은 앱 크기(APK)가 아니라 앱 **데이터**로 쌓입니다. 한 장이 몇 KB라서, 성경 전체를 다 읽어도 대략 5MB 안팎입니다.
- 교독문은 본문(개역개정, 대한성서공회)과 구성(어떤 구절을 어떻게 나눴는지, 한국찬송가공회) 두 겹으로 저작권이 있을 수 있어 저장소에는 번호·제목·성경 범위만 둡니다.
- 개역개정판의 저작권은 대한성서공회에 있습니다. 개인이 읽는 용도로 만든 앱이며, Play 스토어 등에 공개 배포하려면 대한성서공회의 허락이 필요합니다.
- "오늘의 말씀" 목록은 구절 위치(예: `php 4:19`)만 담고 있습니다: `app/src/main/java/com/keon9608/biblewidget/core/DailyVerses.kt`.

## 코드 구조

```
app/src/main/java/com/keon9608/biblewidget/
├── core/                    안드로이드에 의존하지 않는 부분 (JVM 단위 테스트 있음)
│   ├── Bible.kt             66권 목록(사이트 책 코드, 장 수), 장 이동
│   ├── DailyVerses.kt       오늘의 말씀 구절 목록
│   ├── ResponsiveReadings.kt 새찬송가 교독문 번호·제목·성경 범위
│   ├── BskoreaParser.kt     대한성서공회 페이지 HTML → 절 목록
│   └── BibleRepository.kt   장 단위로 받아서 파일로 캐시
├── widget/
│   ├── BibleWidgetProvider.kt  위젯 이벤트(이전/다음 장, 다시 시도, 자정 갱신)
│   ├── WidgetRenderer.kt       둥근 사각형 + 스크롤 목록, 크기에 맞춘 여백
│   ├── VerseListService.kt     스크롤 목록의 각 줄(절) 만들기, 본문 받아오기
│   └── WidgetPrefs.kt          위젯별 설정 저장
└── ui/
    ├── ConfigActivity.kt    위젯 설정 화면 (배경화면 위 미리보기, 투명도·글자 크기 슬라이더)
    ├── MainActivity.kt      앱 첫 화면: 사용법, 위젯 추가, 내 위젯 설정
    └── SystemBars.kt        상태 표시줄·내비게이션 바 뒤까지 그리기
```

사이트의 HTML 구조가 바뀌어 본문을 못 읽게 되면 `BskoreaParser.kt`만 고치면 됩니다.
